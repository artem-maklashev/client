# Рекомендации по тестированию компонента диаграммы Ганта Drywall

## Обзор
Этот документ содержит рекомендации по тестированию компонента диаграммы Ганта для таблицы DrywallTable, включая функциональные и нефункциональные тесты.

## Функциональное тестирование

### 1. Отображение диаграммы Ганта
**Цель:** Проверить корректное отображение диаграммы Ганта с различными наборами данных

**Тест-кейсы:**
- Отображение диаграммы при пустом списке элементов
- Отображение диаграммы с одним элементом
- Отображение диаграммы с несколькими элементами
- Отображение диаграммы с большим количеством элементов (50+)
- Корректное отображение названий гипсокартона на оси Y
- Корректное отображение дат на оси X
- Отображение временных интервалов для каждого элемента

### 2. Переключение между вкладками
**Цель:** Проверить корректную работу переключения между таблицей и диаграммой Ганта

**Тест-кейсы:**
- Переключение с таблицы на диаграмму Ганта
- Переключение с диаграммы Ганта на таблицу
- Сохранение состояния данных при переключении
- Корректное отображение активной вкладки

### 3. Добавление новых элементов
**Цель:** Проверить автоматическое обновление диаграммы при добавлении новых элементов

**Тест-кейсы:**
- Добавление элемента через PlaningItemInput
- Автоматическое обновление диаграммы после добавления
- Корректное отображение нового элемента на диаграмме
- Обновление общего количества для типа гипсокартона

### 4. Редактирование элементов
**Цель:** Проверить обновление диаграммы при редактировании элементов

**Тест-кейсы:**
- Редактирование количества элемента
- Изменение дат начала/окончания производства
- Автоматическое обновление диаграммы после редактирования
- Корректное отображение изменений на диаграмме

### 5. Удаление элементов
**Цель:** Проверить обновление диаграммы при удалении элементов

**Тест-кейсы:**
- Удаление элемента из таблицы
- Автоматическое обновление диаграммы после удаления
- Корректное удаление элемента с диаграммы
- Обновление общего количества для типа гипсокартона

### 6. Группировка по типам гипсокартона
**Цель:** Проверить корректную группировку элементов по типам гипсокартона

**Тест-кейсы:**
- Группировка элементов одного типа
- Группировка элементов разных типов
- Отображение общего количества для каждого типа
- Корректное отображение цветовой кодировки для разных типов

### 2. Интеграционные тесты
```javascript
// Пример интеграционного теста
describe('PlaningPage with Gantt Chart', () => {
  it('should switch between table and gantt views', () => {
    render(<PlaningPage />);
    
    // Проверяем, что по умолчанию отображается таблица
    expect(screen.getByText('Порядок производства гипсокартона')).toBeInTheDocument();
    
    // Переключаемся на диаграмму Ганта
    const ganttTab = screen.getByText('Диаграмма Ганта');
    fireEvent.click(ganttTab);
    
    // Проверяем, что отображается диаграмма Ганта
    expect(screen.getByText('Диаграмма Ганта производства гипсокартона')).toBeInTheDocument();
  });
});
```
